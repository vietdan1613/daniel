## **1️⃣ What is a Shallow Copy?**  
A **shallow copy** creates a new object **with the same reference** to nested objects (i.e., it does **not** clone deeply nested objects).  

### ✅ **Example: Shallow Copy**  
```javascript
const original = { name: "Alice", info: { age: 25 } };

const shallowCopy = { ...original }; // Spread operator creates a shallow copy

shallowCopy.name = "Bob"; // ✅ Modifies only the copy
shallowCopy.info.age = 30; // ❌ Modifies the original too!

console.log(original);      // { name: "Alice", info: { age: 30 } }
console.log(shallowCopy);   // { name: "Bob", info: { age: 30 } }
```
🔹 `shallowCopy.name` is independent, but `info.age` **affects both** objects because **they share the same reference**.  

---

## **2️⃣ What is a Deep Copy?**  
A **deep copy** creates a new object and **recursively copies all nested objects**, ensuring **no shared references**.  

### ✅ **Example: Deep Copy**  
```javascript
const original = { name: "Alice", info: { age: 25 } };

// Deep Copy using JSON methods (⚠️ Won't work for functions or special types)
const deepCopy = JSON.parse(JSON.stringify(original));

deepCopy.info.age = 30;  // ✅ Does not affect the original

console.log(original);    // { name: "Alice", info: { age: 25 } }
console.log(deepCopy);    // { name: "Alice", info: { age: 30 } }
```
🔹 Now `deepCopy.info.age` **does not modify the original object**.

---

## **3️⃣ Key Differences**
| Feature         | Shallow Copy | Deep Copy |
|----------------|-------------|-----------|
| **Copies primitive values?** | ✅ Yes | ✅ Yes |
| **Copies nested objects?** | ❌ No (references kept) | ✅ Yes (fully cloned) |
| **Affects the original when modifying nested objects?** | ✅ Yes | ❌ No |
| **Performance** | 🚀 Faster | 🐢 Slower |

---

## **4️⃣ Methods to Create Copies**
| Method | Type | Supports Nested Objects? |
|--------|------|------------------------|
| `{ ...obj }` (Spread Operator) | Shallow | ❌ No |
| `Object.assign({}, obj)` | Shallow | ❌ No |
| `JSON.parse(JSON.stringify(obj))` | Deep | ✅ Yes (but no functions, Date, RegExp) |
| `structuredClone(obj)` (modern browsers) | Deep | ✅ Yes |

---

## **5️⃣ Best Way to Make a Deep Copy**
### ✅ **Using `structuredClone()` (Recommended)**
```javascript
const original = { name: "Alice", info: { age: 25 } };

const deepCopy = structuredClone(original);

deepCopy.info.age = 30;  // ✅ Doesn't modify original

console.log(original);   // { name: "Alice", info: { age: 25 } }
console.log(deepCopy);   // { name: "Alice", info: { age: 30 } }
```
🔹 `structuredClone()` **supports all data types**, including Dates, Maps, and Sets.

---

## **6️⃣ When to Use Each?**
- **Use a Shallow Copy** when you only need to copy the first level of properties.
- **Use a Deep Copy** when modifying nested objects **without affecting the original**.
