21. **Different ways to define functions in JavaScript?**  
    ```js
    function func() {} // Function Declaration
    const func = function() {}; // Function Expression
    const func = () => {}; // Arrow Function
    ```

22. **Function Declarations vs. Function Expressions?**  
    - Declarations are **hoisted**, expressions are **not**.

23. **Closures in JavaScript?**  
    - A function that retains access to variables from its outer function.

24. **Function scope vs. Block scope?**  
    - `var` is function-scoped.  
    - `let` and `const` are block-scoped.

25. **Arrow functions vs. Regular functions?**  
    - Arrow functions **do not have their own `this`**.

26. **Difference between default parameters and rest parameters?**  
    ```js
    function sum(a = 10, b = 20) {} // Default parameters
    function sum(...numbers) {} // Rest parameters
    ```

27. **Difference between `call()`, `apply()`, and `bind()`?**  
    - `call`: Calls a function with arguments.  
    - `apply`: Calls a function with arguments as an array.  
    - `bind`: Returns a new function.

28. **Pure functions vs. Impure functions?**  
    - Pure functions **do not modify external state**.

29. **What is an IIFE?**  
    ```js
    (function() {
        console.log("Runs immediately!");
    })();
    ```

30. **What is recursion?**  
    - A function that calls itself.

### **Arrays and Objects**
31. **Ways to create an array?**  
    ```js
    let arr = []; 
    let arr2 = new Array();
    ```

32. **Difference between `map()`, `filter()`, `reduce()`?**  
    - `map`: Transforms an array.  
    - `filter`: Returns elements that meet a condition.  
    - `reduce`: Accumulates values.

## 33. **How to remove duplicate elements from an array?**  
    ```js
    let unique = [...new Set([1, 2, 2, 3])];
    ```

## 34. **Shallow copy vs. Deep copy?**  
    - `Object.assign()` creates a **shallow copy**.  
    - `JSON.parse(JSON.stringify(obj))` creates a **deep copy**.

## 35. **What is destructuring?**  
    ```js
    let [a, b] = [10, 20]; // Array Destructuring
    let {x, y} = {x: 5, y: 10}; // Object Destructuring
    ```

## 36. **What is object destructuring, and why is it useful?**  
    - It extracts properties from an object into variables.  

    ```js
    const person = { name: "John", age: 30 };
    const { name, age } = person; 
    console.log(name, age); // John 30
    ```

## 37. **Difference between dot notation and bracket notation in JavaScript?**  
    - **Dot Notation**: `obj.property` (for known property names).  
    - **Bracket Notation**: `obj["property"]` (for dynamic keys).

## 38. **What are getters and setters in JavaScript objects?**  
    - They allow defining custom logic when getting/setting properties.  

    ```js
    let person = {
      firstName: "John",
      lastName: "Doe",
      get fullName() {
        return this.firstName + " " + this.lastName;
      },
      set fullName(name) {
        [this.firstName, this.lastName] = name.split(" ");
      }
    };
    ```

## 39. **How do you check if an object has a specific property?**  
    ```js
    console.log("name" in person); // true
    console.log(person.hasOwnProperty("age")); // true
    ```

## 40. **Difference between `Object.freeze()` and `Object.seal()`?**  
    - `Object.freeze()`: Prevents adding, removing, or modifying properties.  
    - `Object.seal()`: Prevents adding/removing properties but allows modification.
