In JavaScript, `call()`, `apply()`, and `bind()` are methods used to **manipulate the `this` keyword** and invoke functions in different ways.

---

## **1️⃣ `call()` Method**  
The `call()` method invokes a function with a specified `this` value and **arguments passed individually**.

#### ✅ **Example: `call()`**
```javascript
function greet(greeting, punctuation) {
    console.log(`${greeting}, ${this.name}${punctuation}`);
}

const person = { name: "Alice" };

greet.call(person, "Hello", "!");  
// Output: Hello, Alice!
```
✅ `this` refers to `person`, and arguments are passed one by one.

---

## **2️⃣ `apply()` Method**  
The `apply()` method is similar to `call()`, but it **takes arguments as an array**.

#### ✅ **Example: `apply()`**
```javascript
function greet(greeting, punctuation) {
    console.log(`${greeting}, ${this.name}${punctuation}`);
}

const person = { name: "Bob" };

greet.apply(person, ["Hi", "!!"]);  
// Output: Hi, Bob!!
```
✅ `apply()` is useful when arguments are already in an array.

---

## **3️⃣ `bind()` Method**  
The `bind()` method **does not invoke the function immediately**. Instead, it **returns a new function with `this` bound to a specific object**.

#### ✅ **Example: `bind()`**
```javascript
function greet(greeting, punctuation) {
    console.log(`${greeting}, ${this.name}${punctuation}`);
}

const person = { name: "Charlie" };

const boundGreet = greet.bind(person);
boundGreet("Hey", "!");  
// Output: Hey, Charlie!
```
✅ Unlike `call()` and `apply()`, `bind()` **does not execute the function immediately**.

---

## **Key Differences**
| Method | Executes Immediately? | Arguments Passed |
|--------|---------------------|-----------------|
| `call()` | ✅ Yes | Individually (comma-separated) |
| `apply()` | ✅ Yes | As an array |
| `bind()` | ❌ No | Returns a new function |

---

## **Use Case Comparison**
### ✅ **When to Use `call()`?**
Use `call()` when you want to **immediately invoke a function** with `this` set to a specific object and arguments passed individually.

```javascript
const person1 = { name: "John" };
const person2 = { name: "Doe" };

function introduce(city) {
    console.log(`My name is ${this.name} and I live in ${city}.`);
}

introduce.call(person1, "New York");  
// Output: My name is John and I live in New York.

introduce.call(person2, "London");  
// Output: My name is Doe and I live in London.
```

---

### ✅ **When to Use `apply()`?**
Use `apply()` when arguments are **already in an array**.

```javascript
function sum(a, b, c) {
    return a + b + c;
}

console.log(sum.apply(null, [1, 2, 3]));  
// Output: 6
```

---

### ✅ **When to Use `bind()`?**
Use `bind()` when you **want to store the function for later execution**.

```javascript
const user = { name: "Emma" };

function sayHello() {
    console.log(`Hello, ${this.name}!`);
}

const boundHello = sayHello.bind(user);

setTimeout(boundHello, 2000);  
// Output (after 2s): Hello, Emma!
```

---

### **Final Summary**
- `call()`: Executes **immediately**, passing arguments **one by one**.
- `apply()`: Executes **immediately**, passing arguments **as an array**.
- `bind()`: **Returns a new function** (does **not** execute immediately).
