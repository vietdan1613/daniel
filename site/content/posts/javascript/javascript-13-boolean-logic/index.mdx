Boolean logic is the foundation of decision-making in JavaScript. It involves **true/false values**, **logical operators**, and **conditional expressions**.

---

## **1. Boolean Values in JavaScript**  
A boolean value can only be:
- `true`
- `false`

```javascript
console.log(true);  // Output: true
console.log(false); // Output: false
```

---

## **2. Logical Operators**
JavaScript provides **three logical operators** to combine boolean expressions:

| Operator | Name            | Example         | Explanation |
|----------|----------------|----------------|-------------|
| `&&`     | AND            | `true && false` | Returns `true` if **both** operands are `true`. |
| `||`     | OR             | `true || false` | Returns `true` if **at least one** operand is `true`. |
| `!`      | NOT (Negation) | `!true`         | Returns the opposite boolean value. |

---

## **3. Logical AND (`&&`)**  
- **Returns `true` only if both operands are `true`.**  
- If **any operand** is `false`, it returns `false`.

```javascript
console.log(true && true);   // Output: true
console.log(true && false);  // Output: false
console.log(5 > 3 && 10 < 20); // Output: true
console.log(5 > 10 && 10 < 20); // Output: false
```

✅ **Practical Use Case: Checking Multiple Conditions**
```javascript
let age = 25;
let hasID = true;

if (age >= 18 && hasID) {
    console.log("Allowed to enter");
} else {
    console.log("Not allowed");
}
// Output: Allowed to enter
```

---

## **4. Logical OR (`||`)**
- **Returns `true` if at least one operand is `true`.**  
- Returns `false` **only if both operands are `false`.**

```javascript
console.log(true || false);  // Output: true
console.log(false || false); // Output: false
console.log(5 > 10 || 10 < 20); // Output: true
console.log(5 > 10 || 3 > 8);   // Output: false
```

✅ **Practical Use Case: Providing Default Values**
```javascript
let username = "";
let displayName = username || "Guest";

console.log(displayName); // Output: "Guest"
```
💡 **Explanation:** Since `""` is falsy, `"Guest"` is used as a default value.

---

## **5. Logical NOT (`!`)**
- **Reverses** a boolean value.

```javascript
console.log(!true);  // Output: false
console.log(!false); // Output: true
console.log(!(5 > 3)); // Output: false
```

✅ **Practical Use Case: Checking Empty Input**
```javascript
let userInput = "";

if (!userInput) {
    console.log("No input provided");
} else {
    console.log("Input received");
}
// Output: No input provided
```
💡 **Explanation:** `""` is falsy, so `!userInput` becomes `true`.

---

## **6. Operator Precedence (`!` > `&&` > `||`)**
Logical operators have an order of precedence:
1. `!` (NOT) is evaluated first.
2. `&&` (AND) is evaluated second.
3. `||` (OR) is evaluated last.

```javascript
console.log(true || false && false); 
// Output: true (AND is evaluated first, then OR)

console.log(!(true && false) || false); 
// Output: true (NOT applied first, then AND, then OR)
```

---

## **7. Short-Circuit Evaluation**
### **1️⃣ `&&` (AND) Short-Circuit**
- If the first value is **false**, JavaScript **stops** and returns it.
```javascript
console.log(false && "Hello"); // Output: false
console.log(0 && "World"); // Output: 0
```
✅ **Useful for Conditional Execution**
```javascript
let isLoggedIn = true;
isLoggedIn && console.log("Welcome!"); // Output: Welcome!
```
💡 If `isLoggedIn` is `false`, `console.log` won’t run.

---

### **2️⃣ `||` (OR) Short-Circuit**
- If the first value is **true**, JavaScript **stops** and returns it.
```javascript
console.log(true || "Hello"); // Output: true
console.log("JavaScript" || "World"); // Output: "JavaScript"
console.log("" || "Fallback"); // Output: "Fallback"
```

✅ **Useful for Setting Default Values**
```javascript
let name = "";
let user = name || "Anonymous";
console.log(user); // Output: "Anonymous"
```

---

## **8. Combining Logical Operators**
```javascript
let hasMoney = true;
let hasTime = false;

if (hasMoney && hasTime) {
    console.log("Let's go on vacation!");
} else if (hasMoney || hasTime) {
    console.log("Maybe a short trip.");
} else {
    console.log("Stay home.");
}

// Output: "Maybe a short trip."
```
💡 **Explanation:** Since `hasMoney || hasTime` is `true`, `"Maybe a short trip."` is printed.

---

✔ **Understand operator precedence and short-circuiting for cleaner code.**
