JavaScript provides three ways to declare variables: **`let`**, **`const`**, and **`var`**. While they all serve the purpose of storing values, they differ in scope, mutability, and behavior. Here's a breakdown:

---

## **1. `let`**  
Introduced in ES6, `let` is the modern way to declare variables that can be reassigned. It is **block-scoped**, meaning its value is only accessible within the block `{}` in which it is declared.  

### Syntax:
```javascript
let variableName = value;
```

### Features of `let`:
- **Block Scope**: Limited to the enclosing block, function, or global scope.
- **Reassignment Allowed**: The value of a `let` variable can be changed.
- **No Hoisting Issues**: Unlike `var`, `let` is not accessible before declaration.

### Example:
```javascript
{
    let x = 10;
    console.log(x); // Output: 10
}
// console.log(x); // Error: x is not defined
```

```javascript
let age = 25;
age = 30; // Reassignment allowed
console.log(age); // Output: 30
```

---

## **2. `const`**  
Also introduced in ES6, `const` is used to declare variables whose values cannot be reassigned. It is also **block-scoped**.

### Syntax:
```javascript
const variableName = value;
```

### Features of `const`:
- **Block Scope**: Same as `let`.
- **Immutable Reference**: The variable cannot be reassigned, but for objects and arrays, the contents can be modified.
- **Must Be Initialized**: A `const` variable must be assigned a value at the time of declaration.

### Example:
```javascript
const pi = 3.14;
console.log(pi); // Output: 3.14

// pi = 3.14159; // Error: Assignment to constant variable
```

### With Objects:
```javascript
const person = { name: "Alice", age: 30 };
person.age = 31; // Allowed: modifying the contents of the object
console.log(person.age); // Output: 31

// person = {}; // Error: Reassigning the object itself is not allowed
```

---

## **3. `var`**  
`var` is the original way to declare variables in JavaScript. It is **function-scoped**, meaning it is accessible within the function where it is declared. It is also **hoisted**, but with undefined as its value before the declaration is encountered.

### Syntax:
```javascript
var variableName = value;
```

### Features of `var`:
- **Function Scope**: Limited to the function where it is declared. If declared outside, it becomes globally scoped.
- **Reassignment Allowed**: Similar to `let`, the value can be changed.
- **Hoisting**: Variables declared with `var` are moved to the top of their scope during compilation, but their value is not initialized.

### Example:
```javascript
var name = "Alice";
console.log(name); // Output: Alice

name = "Bob"; // Reassignment allowed
console.log(name); // Output: Bob
```

### Hoisting:
```javascript
console.log(a); // Output: undefined (hoisted but uninitialized)
var a = 5;
console.log(a); // Output: 5
```

---

## **Key Differences**

| Feature                | `let`                 | `const`               | `var`                |
|------------------------|-----------------------|-----------------------|----------------------|
| **Scope**              | Block                | Block                | Function            |
| **Reassignment**       | Allowed              | Not Allowed          | Allowed             |
| **Hoisting**           | Not Initialized      | Not Initialized      | Initialized as `undefined` |
| **Global Object**      | Does Not Attach      | Does Not Attach      | Attaches            |
| **Declaration**        | Can Be Declared Later| Must Be Initialized  | Can Be Declared Later |

---

## **Best Practices**
- Use **`const`** by default for values that do not change.
- Use **`let`** for variables whose values need to change over time.
- Avoid **`var`** unless working in older JavaScript codebases or for legacy support.

---

## Final Thoughts
Understanding when to use `let`, `const`, and `var` ensures your code is predictable, secure, and easier to maintain. Opt for `const` whenever possible, fall back to `let` when necessary, and avoid `var` in modern development.
