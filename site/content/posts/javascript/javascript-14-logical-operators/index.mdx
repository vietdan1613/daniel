Logical operators allow you to combine and manipulate boolean values (`true` and `false`). They are commonly used in conditional statements (`if`, `while`, `for`, etc.).  

---

## **1. Types of Logical Operators in JavaScript**
JavaScript provides three main logical operators:

| Operator | Name            | Description |
|----------|----------------|-------------|
| `&&`     | **AND**         | Returns `true` if **both** operands are `true`. |
| `||`     | **OR**          | Returns `true` if **at least one** operand is `true`. |
| `!`      | **NOT**         | Reverses (`negates`) the boolean value. |

---

## **2. Logical AND (`&&`)**
- Returns `true` **only if both** operands are `true`.  
- If **any operand is `false`**, it returns `false`.  

### **Example: AND Operator (`&&`)**
```javascript
console.log(true && true);   // Output: true
console.log(true && false);  // Output: false
console.log(5 > 3 && 10 < 20); // Output: true
console.log(5 > 10 && 10 < 20); // Output: false
```

✅ **Practical Use Case: Checking Multiple Conditions**
```javascript
let age = 25;
let hasID = true;

if (age >= 18 && hasID) {
    console.log("Allowed to enter");
} else {
    console.log("Not allowed");
}
// Output: Allowed to enter
```
💡 **Explanation:**  
- If `age >= 18` **AND** `hasID === true`, the person can enter.  
- If either condition is `false`, entry is denied.  

---

## **3. Logical OR (`||`)**
- Returns `true` **if at least one operand is `true`**.  
- Returns `false` **only if both operands are `false`**.  

### **Example: OR Operator (`||`)**
```javascript
console.log(true || false);  // Output: true
console.log(false || false); // Output: false
console.log(5 > 10 || 10 < 20); // Output: true
console.log(5 > 10 || 3 > 8);   // Output: false
```

✅ **Practical Use Case: Providing Default Values**
```javascript
let username = "";
let displayName = username || "Guest";

console.log(displayName); // Output: "Guest"
```
💡 **Explanation:**  
- Since `""` (empty string) is **falsy**, `"Guest"` is used as a default value.  

---

## **4. Logical NOT (`!`)**
- **Reverses** a boolean value.  
- If the operand is `true`, `!` makes it `false`, and vice versa.  

### **Example: NOT Operator (`!`)**
```javascript
console.log(!true);  // Output: false
console.log(!false); // Output: true
console.log(!(5 > 3)); // Output: false
```

✅ **Practical Use Case: Checking Empty Input**
```javascript
let userInput = "";

if (!userInput) {
    console.log("No input provided");
} else {
    console.log("Input received");
}
// Output: No input provided
```
💡 **Explanation:**  
- `""` is falsy, so `!userInput` becomes `true`, and `"No input provided"` is displayed.

---

## **5. Operator Precedence (`!` > `&&` > `||`)**
Logical operators follow **precedence rules** when used together:
1. **`!` (NOT) is evaluated first.**
2. **`&&` (AND) is evaluated second.**
3. **`||` (OR) is evaluated last.**

### **Example: Operator Precedence**
```javascript
console.log(true || false && false); 
// Output: true (AND is evaluated first, then OR)

console.log(!(true && false) || false); 
// Output: true (NOT applied first, then AND, then OR)
```
💡 **Explanation:**  
- In `true || false && false`, `false && false` is evaluated first (`false`), then `true || false` gives `true`.  
- In `!(true && false) || false`, `true && false` is `false`, `!false` is `true`, and `true || false` is `true`.  

---

## **6. Short-Circuit Evaluation**
Logical operators **stop evaluating** once the result is determined.  

### **1️⃣ `&&` (AND) Short-Circuit**
- If the first value is **false**, JavaScript **stops** and returns it.

```javascript
console.log(false && "Hello"); // Output: false
console.log(0 && "World"); // Output: 0
```

✅ **Useful for Conditional Execution**
```javascript
let isLoggedIn = true;
isLoggedIn && console.log("Welcome!"); // Output: Welcome!
```
💡 **If `isLoggedIn` is `false`, `console.log` won’t run.**  

---

### **2️⃣ `||` (OR) Short-Circuit**
- If the first value is **true**, JavaScript **stops** and returns it.

```javascript
console.log(true || "Hello"); // Output: true
console.log("JavaScript" || "World"); // Output: "JavaScript"
console.log("" || "Fallback"); // Output: "Fallback"
```

✅ **Useful for Setting Default Values**
```javascript
let name = "";
let user = name || "Anonymous";
console.log(user); // Output: "Anonymous"
```
💡 **If `name` is falsy, `"Anonymous"` is used instead.**  

---

## **7. Combining Logical Operators**
```javascript
let hasMoney = true;
let hasTime = false;

if (hasMoney && hasTime) {
    console.log("Let's go on vacation!");
} else if (hasMoney || hasTime) {
    console.log("Maybe a short trip.");
} else {
    console.log("Stay home.");
}

// Output: "Maybe a short trip."
```
💡 **Explanation:**  
- Since `hasMoney || hasTime` is `true`, `"Maybe a short trip."` is printed.  

---

## **8. Summary of Logical Operators**
| Operator | Name  | Description | Example |
|----------|-------|-------------|---------|
| `&&`     | AND   | Returns `true` if **both** values are `true`. | `true && false // false` |
| `||`     | OR    | Returns `true` if **at least one** value is `true`. | `true || false // true` |
| `!`      | NOT   | Reverses a boolean value. | `!true // false` |

---

## **9. Final Thoughts**
✔ **Use `&&` for multiple conditions that must all be `true`.**  
✔ **Use `||` for fallback/default values.**  
✔ **Use `!` to reverse a boolean value.**  
✔ **Understand short-circuiting to optimize performance.**
