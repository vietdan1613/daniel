The **ternary operator (`? :`)** is a **shorthand for `if...else` statements** in JavaScript. It allows you to write concise and readable conditional expressions.

---

## **1. Basic Syntax**
```javascript
condition ? expression_if_true : expression_if_false;
```
✔ **`condition`** → A boolean expression that evaluates to `true` or `false`.  
✔ **`expression_if_true`** → Runs if the condition is `true`.  
✔ **`expression_if_false`** → Runs if the condition is `false`.  

---

## **2. Example: Using the Ternary Operator**
```javascript
let age = 18;
let message = age >= 18 ? "You are an adult" : "You are a minor";
console.log(message);
```
### **Output:**  
```
You are an adult
```
💡 **Explanation:**  
- If `age` is **18 or more**, the result is `"You are an adult"`.  
- Otherwise, it returns `"You are a minor"`.  

---

## **3. Ternary vs. `if...else`**
The ternary operator is a **shorter alternative** to `if...else`.

### **Using `if...else`**
```javascript
let age = 18;
let message;

if (age >= 18) {
    message = "You are an adult";
} else {
    message = "You are a minor";
}

console.log(message);
```
✔ **Ternary Operator Equivalent:**
```javascript
let message = age >= 18 ? "You are an adult" : "You are a minor";
```
✔ **Much shorter and cleaner!**  

---

## **4. Using the Ternary Operator in Functions**
```javascript
function checkNumber(num) {
    return num > 0 ? "Positive" : "Negative or Zero";
}

console.log(checkNumber(5));  // Positive
console.log(checkNumber(-2)); // Negative or Zero
```
💡 **Here, `checkNumber(num)` returns `"Positive"` if `num > 0`, otherwise `"Negative or Zero"`**.

---

## **5. Nesting Ternary Operators**
You can nest multiple ternary operators, but be careful with readability.

```javascript
let score = 85;
let grade = score >= 90 ? "A" : score >= 80 ? "B" : score >= 70 ? "C" : "F";

console.log(grade); // Output: "B"
```
💡 **Explanation:**  
- If `score >= 90`, return `"A"`.  
- Else if `score >= 80`, return `"B"`.  
- Else if `score >= 70`, return `"C"`.  
- Otherwise, return `"F"`.  

🚨 **Warning:** Nesting too many ternary operators can reduce code readability. Consider using `if...else` in complex cases.

---

## **6. Using Ternary Inside Template Literals**
The ternary operator is useful inside template literals.

```javascript
let loggedIn = true;
console.log(`Welcome, ${loggedIn ? "User" : "Guest"}!`);
```
✔ **Output:** `"Welcome, User!"` if `loggedIn = true`, otherwise `"Welcome, Guest!"`.

---

## **7. When to Use the Ternary Operator?**
✅ **Use it when:**
- The condition is simple.
- It improves code readability.
- You are assigning a value based on a condition.

🚫 **Avoid it when:**
- The condition is complex and makes the code hard to read.
- You need multiple statements inside each condition (use `if...else` instead).

---

## **8. Summary**
| Feature | Ternary Operator (`? :`) | `if...else` |
|---------|----------------------|------------|
| **Syntax** | Short and concise | Longer |
| **Readability** | Good for simple conditions | Better for complex logic |
| **Use Case** | Assigning values | Executing multiple statements |

---
