## 41. **Difference between `setTimeout()` and `setInterval()`?**  
    - `setTimeout()`: Executes a function **once** after a delay.  
    - `setInterval()`: Executes a function **repeatedly** after a delay.

    ```js
    setTimeout(() => console.log("Hello"), 1000); // Runs once after 1s
    setInterval(() => console.log("World"), 1000); // Runs every 1s
    ```

42. **What is a Promise, and how does it work?**  
    - A Promise represents a value that may be available in the future.  
    - It can be **pending, fulfilled, or rejected**.

    ```js
    let promise = new Promise((resolve, reject) => {
      setTimeout(() => resolve("Done!"), 1000);
    });
    promise.then(console.log); // Prints "Done!" after 1 second
    ```

43. **What is async/await, and how does it simplify working with Promises?**  
    - It makes asynchronous code look synchronous.  
    - `await` pauses execution until the Promise resolves.

    ```js
    async function fetchData() {
      let data = await fetch("https://api.example.com");
      console.log(data);
    }
    ```

44. **How do you handle errors in async/await functions?**  
    - Use `try...catch`:

    ```js
    async function fetchData() {
      try {
        let data = await fetch("https://api.example.com");
        console.log(data);
      } catch (error) {
        console.log("Error:", error);
      }
    }
    ```

45. **What is the difference between microtasks and macrotasks in JavaScript?**  
    - **Microtasks**: Executed immediately after the current task (`Promises`).  
    - **Macrotasks**: Scheduled for the next event loop cycle (`setTimeout`).

46. **What are prototypes in JavaScript, and how do they enable inheritance?**  
    - Every JavaScript object has a `prototype` that allows property inheritance.

    ```js
    function Person(name) {
      this.name = name;
    }
    Person.prototype.sayHello = function () {
      console.log("Hello, " + this.name);
    };
    let john = new Person("John");
    john.sayHello(); // Hello, John
    ```

47. **Difference between prototypal inheritance and classical inheritance?**  
    - **Classical (OOP)**: Uses `class` and `extends`.  
    - **Prototypal**: Objects inherit directly from other objects.

48. **Explain the concept of "hoisting" in JavaScript.**  
    - Variables and functions are moved to the top of their scope before execution.

    ```js
    console.log(a); // undefined
    var a = 5; // Hoisted with undefined

    foo(); // "Hello"
    function foo() {
      console.log("Hello");
    }
    ```

49. **What are JavaScript generators (`function*`), and when should you use them?**  
    - Generators return values lazily using `yield`.

    ```js
    function* generatorFunc() {
      yield "Hello";
      yield "World";
    }
    let gen = generatorFunc();
    console.log(gen.next().value); // "Hello"
    console.log(gen.next().value); // "World"
    ```

50. **How does JavaScript handle memory management and garbage collection?**  
    - JavaScript uses **automatic garbage collection**, removing unused objects.  
    - Uses **Reference Counting** and **Mark-and-Sweep Algorithm**.
