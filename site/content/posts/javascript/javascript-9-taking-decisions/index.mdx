In JavaScript, decision-making is done using conditional statements like **`if`**, **`else if`**, and **`else`**. These allow your program to execute different code blocks depending on conditions.

---

## **1. `if` Statement**  
The **`if`** statement executes a block of code **only if** the condition is `true`.

### **Syntax:**
```javascript
if (condition) {
    // Code to execute if the condition is true
}
```

### **Example:**
```javascript
let age = 18;

if (age >= 18) {
    console.log("You are an adult.");
}

// Output: You are an adult.
```

---

## **2. `if...else` Statement**  
The **`else`** block executes **if the `if` condition is false**.

### **Syntax:**
```javascript
if (condition) {
    // Code if condition is true
} else {
    // Code if condition is false
}
```

### **Example:**
```javascript
let age = 16;

if (age >= 18) {
    console.log("You can vote.");
} else {
    console.log("You cannot vote yet.");
}

// Output: You cannot vote yet.
```

---

## **3. `if...else if...else` Statement**  
Use **`else if`** to check multiple conditions.

### **Syntax:**
```javascript
if (condition1) {
    // Code if condition1 is true
} else if (condition2) {
    // Code if condition2 is true
} else {
    // Code if none of the conditions are true
}
```

### **Example:**
```javascript
let score = 85;

if (score >= 90) {
    console.log("Grade: A");
} else if (score >= 80) {
    console.log("Grade: B");
} else if (score >= 70) {
    console.log("Grade: C");
} else {
    console.log("Grade: F");
}

// Output: Grade: B
```

---

## **4. Nested `if` Statements**  
You can place one `if` statement inside another.

### **Example:**
```javascript
let num = 10;

if (num > 0) {
    console.log("Number is positive.");
    
    if (num % 2 === 0) {
        console.log("It is even.");
    }
}

// Output: 
// Number is positive.
// It is even.
```

---

## **5. Ternary Operator (`? :`)**  
A **shorter way** to write `if...else` statements.

### **Syntax:**
```javascript
condition ? value_if_true : value_if_false;
```

### **Example:**
```javascript
let age = 18;
let canVote = (age >= 18) ? "Yes, you can vote!" : "No, you cannot vote.";
console.log(canVote);

// Output: Yes, you can vote!
```

✅ **Use the ternary operator** for simple `if...else` statements.

---

## **6. Logical Operators with `if` Statements**
You can use logical operators (`&&`, `||`, `!`) inside `if` conditions.

### **Example:**
```javascript
let isAdult = true;
let hasID = false;

if (isAdult && hasID) {
    console.log("You can enter.");
} else {
    console.log("You cannot enter.");
}

// Output: You cannot enter.
```

---

## **7. `if` Statement Best Practices**
✔ **Always use `{}`** for better readability.  
✔ **Use `else if` instead of multiple `if` checks** for efficiency.  
✔ **Prefer ternary operators (`? :`)** for simple conditions.  
✔ **Avoid deep nesting**—use functions if needed.

---

### **Final Thoughts**
The `if / else` statement is a fundamental building block for decision-making in JavaScript. Understanding it well will help you write **clean, efficient, and logical** code! 🚀
