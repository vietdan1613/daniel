## 41. What is server-side rendering (SSR) in React?
Server-side rendering (SSR) renders React components on the server before sending the HTML to the client. It improves performance and SEO.

## 42. What is static site generation (SSG)?
SSG pre-builds HTML at build time instead of runtime, improving performance and caching.

## 43. What is hydration in React?
Hydration is the process where React attaches event listeners to the pre-rendered HTML from SSR or SSG.

## 44. What is progressive web app (PWA) support in React?
React supports PWAs, which are web applications with offline capabilities, push notifications, and fast loading speeds.

## 45. What is React Fiber?
React Fiber is the new reconciliation algorithm that improves rendering performance and enables features like Suspense and concurrent rendering.

## 46. What is concurrent rendering in React?
Concurrent rendering allows React to work on multiple UI updates at the same time, improving responsiveness.

## 47. What are React Suspense and React.lazy?
Suspense allows React to wait for asynchronous operations, while `React.lazy` enables dynamic imports.
```jsx
const LazyComponent = React.lazy(() => import('./LazyComponent'));
```

## 48. What is React Portals?
React Portals allow rendering children into a different part of the DOM outside of the component hierarchy.
```jsx
ReactDOM.createPortal(child, container);
```

## 49. What is the difference between Redux and React Context API?
Redux provides centralized state management with middleware support, while Context API is built into React for smaller-scale state management.

## 50. How do you optimize large lists in React?
Using virtualization libraries like `react-window` or `react-virtualized` to render only visible items.

## 51. What is Webpack and why is it used in React?
Webpack is a module bundler that optimizes JavaScript, CSS, and assets for better performance.

## 52. What are React hooks rules?
Hooks must be called at the top level of a function and only inside React components or custom hooks.

## 53. How does React handle memory leaks?
React handles memory leaks by cleaning up side effects in `useEffect` with return functions.
```jsx
useEffect(() => {
  const interval = setInterval(() => console.log("Running"), 1000);
  return () => clearInterval(interval);
}, []);
```

## 54. What is rehydration in Next.js?
Rehydration is the process of making the pre-rendered HTML interactive by attaching React event listeners.

## 55. How do you handle authentication in React?
Using authentication libraries like Firebase, Auth0, or JWT-based authentication.

## 56. What is an atomic design pattern in React?
Atomic design divides UI components into atoms, molecules, organisms, templates, and pages for reusability.

## 57. What are micro frontends in React?
Micro frontends allow building frontend applications as independent modules for scalability.

## 58. What is the difference between shallow and deep rendering in React testing?
Shallow rendering tests a component in isolation, while deep rendering tests all child components.

## 59. How do you improve performance in React applications?
Using memoization, code splitting, lazy loading, virtualized lists, and optimizing re-renders.

## 60. What is tree shaking in React?
Tree shaking removes unused JavaScript code during bundling, reducing file size.
