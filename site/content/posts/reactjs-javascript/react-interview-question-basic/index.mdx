## 1. What is ReactJS?
ReactJS is a JavaScript library developed by Facebook for building user interfaces, especially single-page applications where UI updates dynamically.

## 2. What are the key features of React?
- **JSX**: A syntax extension for JavaScript
- **Virtual DOM**: Enhances performance by updating only changed parts of the UI
- **Components**: Reusable UI elements
- **Unidirectional data flow**: Ensures predictable UI updates
- **Hooks**: Enable state and side effects in functional components

## 3. What is JSX?
JSX (JavaScript XML) is a syntax extension that allows writing HTML-like code inside JavaScript files.

## 4. What is the Virtual DOM?
The Virtual DOM is a lightweight copy of the actual DOM. React updates it first, compares it with the previous version, and then updates only the necessary parts of the real DOM.

## 5. What are props in React?
Props (short for properties) allow passing data from parent to child components in React.

## 6. What is state in React?
State is a built-in object that allows components to maintain internal data.

## 7. What is the difference between state and props?
- **Props**: Read-only, passed from parent to child
- **State**: Managed within the component, mutable

## 8. How do you create a React component?
React components can be created as **function components** or **class components**.
```jsx
function MyComponent() {
  return <h1>Hello, React!</h1>;
}
```

## 9. What are the two types of components in React?
- **Functional components**: Defined using functions (recommended)
- **Class components**: Defined using ES6 classes

## 10. What is a functional component?
A functional component is a JavaScript function that returns JSX.

## 11. What is a class component?
A class component is a JavaScript class that extends `React.Component` and contains a `render()` method.

## 12. What is the difference between a functional component and a class component?
Functional components are simpler and use hooks, while class components use lifecycle methods.

## 13. What is the significance of keys in React?
Keys help React identify which items have changed, added, or removed in lists.

## 14. What is the role of the render() method in React?
It returns JSX to define the UI of the component.

## 15. What is React Fragment?
Fragments (`<></>`) allow grouping elements without adding extra nodes to the DOM.

## 16. What are controlled and uncontrolled components?
- **Controlled**: Form elements controlled via React state
- **Uncontrolled**: Form elements controlled via the DOM

## 17. What are React hooks?
Hooks are functions that allow using state and lifecycle features in functional components.

## 18. What is the useState hook?
`useState` allows functional components to have local state.
```jsx
const [count, setCount] = useState(0);
```

## 19. What is the useEffect hook?
`useEffect` handles side effects like data fetching, DOM updates, or subscriptions.

## 20. What is the useRef hook?
`useRef` provides a reference to DOM elements or persistent values across renders.
