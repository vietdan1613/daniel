## 21. What is the purpose of React Router?
It enables navigation without full-page reloads in single-page applications by providing dynamic routing capabilities.

## 22. How do you pass data from parent to child components?
Using props:
```jsx
<ChildComponent data={someData} />
```

## 23. How do you pass data from child to parent components?
Using callback functions provided by the parent.
```jsx
const handleData = (childData) => {
  console.log(childData);
};
<ChildComponent sendData={handleData} />
```

## 24. What is the Context API in React?
The Context API is a state management solution that allows passing data globally without prop drilling.

## 25. What is the difference between React's Context API and Redux?
Context API is built-in and simpler, while Redux is more structured and powerful for complex state management.

## 26. What is React.memo?
`React.memo` is a higher-order component that prevents unnecessary re-renders of functional components.

## 27. What is the difference between useMemo and useCallback?
- `useMemo` memoizes values
- `useCallback` memoizes functions

## 28. What is the difference between useEffect and useLayoutEffect?
`useLayoutEffect` runs synchronously after rendering, while `useEffect` runs asynchronously after rendering.

## 29. What are higher-order components (HOCs)?
HOCs are functions that take a component and return a new component with enhanced functionality.

## 30. What are pure components in React?
Pure components optimize performance by preventing unnecessary re-renders using shallow prop and state comparisons.

## 31. What is lazy loading in React?
Lazy loading delays the loading of components until they are needed, improving performance.
```jsx
const LazyComponent = React.lazy(() => import('./LazyComponent'));
```

## 32. What is suspense in React?
Suspense allows React to handle asynchronous rendering while waiting for lazy-loaded components.

## 33. How does React handle forms?
React handles forms using controlled components where form elements are managed by state.

## 34. How do you optimize React performance?
Using memoization, lazy loading, pure components, and efficient state management.

## 35. What is reconciliation in React?
Reconciliation is React's process of updating the Virtual DOM and efficiently applying changes to the real DOM.

## 36. What are synthetic events in React?
Synthetic events are React's wrapper around browser-native events, ensuring cross-browser compatibility.

## 37. What is an error boundary in React?
An error boundary is a React component that catches JavaScript errors in child components and displays a fallback UI.

## 38. What is the significance of defaultProps in React?
`defaultProps` provides default values for props when none are specified.
```jsx
Component.defaultProps = { color: 'blue' };
```

## 39. What is the significance of PropTypes in React?
`PropTypes` help validate the types of props passed to components.
```jsx
Component.propTypes = { name: PropTypes.string };
```

## 40. How do you handle side effects in React?
Using `useEffect` to manage asynchronous actions, subscriptions, and event listeners.
