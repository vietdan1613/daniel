Tic Tac Toe might be a simple game on the surface, but it's a brilliant playground for 
practicing **React fundamentals**. In this tutorial, you'll build a smart, persistent, 
and interactive version of Tic Tac Toe using:

* ✅ `useState` with functional updates and lazy initialization
* 🔁 `useEffect` to synchronize state with `localStorage`
* 🧠 Derived state for game logic
* 🕹️ Game history (aka “time travel”)

Let’s break down everything step by step.

---

## 🧱 Phase 1: Managing Game State with `useState`

To start, we manage our game board using `useState`. Instead of using a 2D array, we 
use a 1D array with 9 slots (like a flat 3x3 grid):

```tsx
const [squares, setSquares] = useState(Array(9).fill(null))
```

Each square can be `"X"`, `"O"`, or `null`.

### ✅ Functional Updates with `setState`

```tsx
setCount(count + 1) 
// ✅ becomes:
setCount(prevCount => prevCount + 1)
```

> 🧠 **Rule of Thumb**:
> Use the **function form** of `setState` when the next state depends on the **previous state**.

---

## 🧠 Phase 2: Derived State – `nextValue` and `winner`

Some values in your app don’t need to be stored explicitly. Instead, you **derive** them from existing state:

### `nextValue`

```tsx
function calculateNextValue(squares) {
  const xCount = squares.filter(s => s === 'X').length
  const oCount = squares.filter(s => s === 'O').length
  return xCount === oCount ? 'X' : 'O'
}
```

### `winner`

This is derived using a helper:

```tsx
function calculateWinner(squares) {
  const lines = [
    [0, 1, 2], [3, 4, 5], [6, 7, 8],
    [0, 3, 6], [1, 4, 7], [2, 5, 8],
    [0, 4, 8], [2, 4, 6],
  ]
  for (const [a, b, c] of lines) {
    if (squares[a] && squares[a] === squares[b] && squares[a] === squares[c]) {
      return squares[a]
    }
  }
  return null
}
```

## 💾 Phase 3: Persist State in `localStorage`

We want to make sure that the player can **resume their game** after closing the tab.

### 🎈 Lazy Initialization from `localStorage`

```tsx
const [squares, setSquares] = useState(() => {
  const stored = window.localStorage.getItem('tic-tac-toe:squares')
  return stored ? JSON.parse(stored) : Array(9).fill(null)
})
```

Using a function here means this runs only once — during the initial render.

### 🔁 Save to `localStorage` on Updates

```tsx
useEffect(() => {
  window.localStorage.setItem('tic-tac-toe:squares', JSON.stringify(squares))
}, [squares])
```

> ✅ This keeps our `localStorage` in sync every time the board updates.

## 🧭 Phase 4: Add Game History ("Time Travel")

Now comes the fun part — implementing game history so users can:

* Go back to previous moves
* Replay the game
* Modify past turns

### 📚 Store All Past States

```tsx
const [history, setHistory] = useState([Array(9).fill(null)])
const [currentStep, setCurrentStep] = useState(0)
```

### 🧮 Current Board is Derived

```tsx
const currentSquares = history[currentStep]
```

You no longer manage `squares` directly. Instead, the game renders from `currentSquares`.

### 🎯 Make a Move

```tsx
function selectSquare(squareIndex) {
  if (winner || currentSquares[squareIndex]) return

  const newHistory = history.slice(0, currentStep + 1)
  const newSquares = [...currentSquares]
  newSquares[squareIndex] = calculateNextValue(currentSquares)

  setHistory([...newHistory, newSquares])
  setCurrentStep(newHistory.length)
}
```

This approach ensures that if the user has time-traveled back and makes a move, it **overwrites** future moves.

### 🔙 Jump to a Previous Move

```tsx
function jumpTo(step) {
  setCurrentStep(step)
}
```

### 🧹 Reset Game

```tsx
function restart() {
  setHistory([Array(9).fill(null)])
  setCurrentStep(0)
  window.localStorage.removeItem('tic-tac-toe:squares')
}
```

---

## 🖥️ UI: Time Travel Buttons

```tsx
<ul>
  {history.map((_, step) => (
    <li key={step}>
      <button disabled={step === currentStep} onClick={() => jumpTo(step)}>
        {step === 0 ? 'Go to game start' : `Go to move #${step}`}
      </button>
    </li>
  ))}
</ul>
```

This list gives players full control over the move timeline.
