## Tree structure

DOM stands for Document Object Model. It’s like a tree structure that represents everything 
on a web page — every tag, text, image, etc.

The DOM is something like this:

![example](./1.png 'example')

## Nodes (element, attribute, text)

If you have this HTML:

```html
<body>
  <h1>Hello</h1>
  <p>Welcome to the site.</p>
</body>
```

The DOM turns it into a tree of objects like this:

```
<body>
 ├── <h1>Hello</h1>
 └── <p>Welcome to the site.</p>
```

## JavaScript interaction

- Change text: document.querySelector('h1').textContent = "Hi!"
- Add/remove elements
- Update styles
- React to user actions (click, scroll, etc.)

```html
<html>
	<body>
		<script type="module">
			const element = document.createElement('div')
			element.textContent = 'Hello World'
			document.body.append(element)
		</script>
	</body>
</html>
```

The browser has to parse the JavaScript code, execute it,
and then generate the DOM from the JavaScript code before displaying things to
the user.

## Browser API

The DOM is not part of JavaScript itself — it's part of the Web APIs provided by the browser. 
It's also worth noting that modifying the DOM can be performance-intensive, so minimizing direct 
manipulation is important in large applications. That's why libraries like React use virtual 
DOMs to optimize rendering.
