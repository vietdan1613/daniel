## Using JSX

JSX is more intuitive than the raw React API and is easier to understand when
reading the code. It's fairly simple HTML-like syntactic sugar on top of the raw
React APIs:

```tsx
const element = <h1 id="greeting">Hey there</h1>

// ↓ ↓ ↓ ↓ compiles to ↓ ↓ ↓ ↓

const element = createElement('h1', {
	id: 'greeting',
	children: 'Hey there',
})
```

Because JSX is not actually JavaScript, you have to convert it using something
called a code compiler. [Babel](https://babeljs.io) is one such tool.

## Interpolation

Interpolation means inserting variables or expressions into something, like a string or a piece of HTML.

```tsx
const children = 'Hello World'
const className = 'container'
const element = <div className={className}>{children}</div>
```

###  You can use:

- Variables: {name}
- Expressions: {2 + 2}
- Function calls: {getMessage()}

## Spread props

Spread props let you pass all the properties of an object to a component 
at once, using the spread syntax (...).

```tsx
const children = 'Hello World'
const className = 'container'
const props = { children, className }
const element = <div {...props} />
```

### Watch out:

- Be careful not to accidentally pass too many props.
- You can still override values:

```tsx
<MyComponent {...user} name="John" />  // name will be "John"
```

## Fragments

Fragments let you group multiple elements in React without adding extra HTML to the DOM.

```tsx
const element = (
  <>
    <h1>Title</h1>
    <p>Description</p>
  </>
)
```
