## 101. What is server-side rendering (SSR) in React?
SSR is the process of rendering React components on the server instead of the browser. This improves SEO and initial load performance. Next.js is a popular framework for SSR in React.

## 102. What is static site generation (SSG) in React?
SSG pre-renders pages at build time, generating static HTML files that can be served instantly. Next.js supports SSG with `getStaticProps`.

## 103. What is hydration in React?
Hydration is the process where React attaches event listeners to a server-rendered HTML page, making it interactive.

## 104. What is React Fiber?
React Fiber is the reimplementation of React’s core algorithm, making rendering more efficient and enabling features like concurrency.

## 105. What are React Portals?
Portals allow rendering a component’s children into a different part of the DOM outside the parent component.
```js
ReactDOM.createPortal(<ChildComponent />, document.getElementById('portal-root'));
```

## 106. What is Concurrent Mode in React?
Concurrent Mode enhances React’s rendering capabilities, allowing non-blocking updates and improved responsiveness. Features like `useTransition` leverage Concurrent Mode.

## 107. What are Suspense and Error Boundaries in React?
- **Suspense** lets you delay rendering components until some condition is met (e.g., data fetching).
- **Error Boundaries** catch errors in child components and display fallback UI instead of crashing the app.

## 108. How does React handle memory leaks?
- Cleaning up event listeners in `useEffect`.
- Using `AbortController` for API requests.
- Unsubscribing from subscriptions when a component unmounts.

## 109. What is React Server Components (RSC)?
RSC is a new feature allowing components to run on the server, reducing JavaScript bundle size and improving performance.

## 110. How do you optimize React for SEO?
- Use SSR or SSG with Next.js.
- Implement meta tags with `react-helmet`.
- Ensure fast loading speeds for better indexing.
